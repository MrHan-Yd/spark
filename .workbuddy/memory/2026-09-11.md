**环境发现（重要，已写进 ~/.workbuddy/MEMORY.md）**：沙箱 shell 缺 `PROGRAMDATA`/`ProgramFiles`/
`APPDATA` 时，NuGet 的 `ConfigurationDefaults` 静态初始化直接抛

## 插件打包 + registry 生成流水线（用户选定方向，已落地）

新增 `scripts/pack_plugins.ps1`（ASCII-only，~330 行），把 `plugins\<id>\` 源码变成可发布的仓库产物：

```
plugins/dist/
  registry.json                          # schema=1 索引（tags + versions[].signature 摘要）
  <id>/<version>/                        # 版本目录：签名单位 + versions[].path 指向对象
  packages/<id>-<version>.spark-plugin   # 预打包 zip（根含 plugin.json，签名后含 signature.json）
```

**关键设计（都是踩过/trap 过才写下来的）**
- **顺序不可拆**：stage → sign → pack → index。签名必须在打包 zip 之前（否则包内缺
  signature.json）；索引必须在签名之后生成（才能写入 `versions[].signature` 摘要，供市场在
  不下载的情况下预显"官方"角标）。
- **装配版本目录先删后建**：上一次签名留下的 `signature.json` 若被复制进新包，客户端会判
  「签名失效（可能被篡改）」。
- 路径模式（默认，给 zipball 提取）vs 直链模式（`-BaseUrl`，写 url+sha256+size）；**两种都已实测**。
- 历史版本目录保留并作为 path-only 条目进索引（保护已 pin 的安装）。
- `tags`/`homepage`/`icon` 属**索引**而非插件清单 → 侧车 `plugins/<id>/market.json`，打包期按
  客户端同款规则校验（≤12 字符/≤4 个/无控制字符/忽略大小写去重），不合规**直接失败**。
- 三道自检：写盘后 round-trip 解析核对；每个 `versions[].path` 必须在磁盘上真实存在且含
  plugin.json；**JSON 键必须全部能映射到 C# DTO 的 `[JsonPropertyName]`**（从
  `ui/Spark.UI/Models/RegistryDto.cs` 现解析，防字段名拼错被客户端静默忽略）。
- 手写 JSON 而非 `ConvertTo-Json`：PS 5.1 会把非 ASCII 转成 `\uXXXX`、PS 7 不会，索引 diff 会
  随 shell 变化；手写 + round-trip 自检兼顾稳定与安全。UTF-8 **无 BOM**（serde_json 与
  System.Text.Json 都拒 BOM）。
- `[Console]::OutputEncoding = UTF8`：否则 cargo/spark-sign 的中文输出被按 ANSI 解码，
  `signing-log.txt` 审计产物变乱码。

**CI 接入**（`.github/workflows/release.yml`）：新增 `Pack and sign official plugins` 步骤，
签名由本脚本一并完成（原独立签名步骤删除）。**注意契约变更**：签名对象从 `<OutDir>/<id>/`
改为 `<OutDir>/<id>/<version>/`（旧循环 `Get-ChildItem $dist -Directory` 会签错层级），
已同步修正；新增 plugin-warehouse 产物上传。

**实测**（PowerShell 工具，`-Configuration debug -SkipBuild` 复用产物）：
- `-Clean -Sign -ZipballUrl …` → 2 插件签名成功、`check-registry` 报 0 错误 / 0 警告、
  registry.json 键全部映射 DTO、中文 tags 原样保留（无 BOM）。
- `-Clean -BaseUrl …` → 直链模式 url/sha256/size 正确（sha256 与 summary 前缀一致）。

**未做（运维依赖，我碰不了）**：正式 `spark-official-v1` 密钥仍需离线机 keygen 并更新
`TRUSTED_KEYS`；`keys/` 里现为开发密钥。另：zip 的 sha256 每次重跑会变（zip 条目时间戳来自
文件 mtime），路径模式不受影响、直链模式同一次运行内自洽，故不修。
