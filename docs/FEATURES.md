# Spark — 功能设计

> 产品名：**Spark**  
> 本文描述**对用户可见的功能**与交互，不展开实现细节。  
> 技术栈定稿见 [TECH_STACK.md](./TECH_STACK.md)；架构/设计见 [ARCHITECTURE.md](./ARCHITECTURE.md)、[DESIGN.md](./DESIGN.md)。

---

## 1. 产品定位

| 项 | 说明 |
|----|------|
| 一句话 | **Spark** — Windows 上按快捷键即可搜索并执行一切的效率启动器 |
| 对标 | uTools / PowerToys Run / Raycast（仅 Windows） |
| 差异 | Rust 性能核心 + 原生 WinUI 壳；开放插件；默认极简、可扩展 |
| 目标用户 | 重度键鼠用户、开发者、办公效率用户 |
| 技术（摘要） | Host=Rust，UI=C# WinUI 3，插件=独立进程（详见 TECH_STACK） |

---

## 2. 设计原则（功能侧）

1. **先出结果再完美**：输入即搜，本地结果优先，插件结果可后到补齐  
2. **默认零配置可用**：装完用默认热键就能搜应用、历史  
3. **主路径极短**：唤起 → 输入 → Enter，尽量三步内完成  
4. **插件不打扰**：未触发的插件不占资源、不弹窗  
5. **可撤销、可关闭**：热键可改、插件可禁用、权限可收

## 4. 核心功能详述

### 4.1 全局唤起

| 项 | 规格 |
|----|------|
| 默认热键 | **Alt + Space** |
| 设置可改 | **Ctrl + Space** 及其他自定义组合 |
| 冲突 | 注册失败时提示，并保留原热键或引导重设 |
| 唤起表现 | 当前屏居中偏上弹出；输入框已聚焦；IME 可正常使用 |
| 隐藏 | Esc；点击窗外（可配）；执行成功后（可配） |
| 托盘 | 左键唤起；右键：设置 / 暂停热键 / 退出 |
| 单实例 | 重复启动只唤起已有实例 |
| 暂停热键 | 托盘可临时禁用（游戏/演示场景） |

**不包含（一期）：** 鼠标划词唤起、全局中键，可作为后续插件或实验功能。

---

### 4.2 主搜索面板

#### 布局

```
┌──────────────────────────────────────────┐
│  🔍  输入框（占位：搜索应用、文件、命令…）   │
├──────────────────────────────────────────┤
│  图标  标题                         来源  │
│  图标  标题 · 副标题                      │
│  …（最多约 9 条可视，可滚）                 │
├──────────────────────────────────────────┤
│  Enter 打开 · Tab 动作 · Esc 关闭         │
└──────────────────────────────────────────┘
```

#### 输入与结果

| 行为 | 说明 |
|------|------|
| 即时搜索 | 输入变化后短防抖（约 50ms）刷新 |
| 空输入 | 显示：最近使用、收藏、建议命令 |
| 有输入 | 混合：应用 > 匹配命令/插件 > 文件（若开启）> 其他 |
| 无结果 | 明确空态文案；可提示「安装插件」或「配置索引目录」 |
| 来源标识 | 每条显示来源（应用 / 文件 / 插件名 / 历史） |
| 流式更新 | 本地结果先到；插件结果稍后插入且不打断当前选中（尽量） |

#### 键盘操作

| 按键 | 功能 |
|------|------|
| `↑` / `↓` | 上下选择 |
| `Enter` | 执行默认动作 |
| `Ctrl+Enter` 或 `Alt+Enter` | 次要动作（如打开目录） |
| `Tab` | 展开当前项可用动作 / 补全前缀（可配置优先级） |
| `Esc` | 有内容则清空；无内容则隐藏 |
| `Ctrl+1…9` | 直接执行第 N 条（可选，设置开关） |

#### 鼠标

- 单击选中；双击执行默认动作  
- 右键：动作菜单（与 Tab 一致）

### 4.3 应用搜索与启动（内置）

| 能力 | 说明 |
|------|------|
| 索引来源 | 开始菜单快捷方式、常见安装位置、UWP/Store 应用（能力范围内） |
| 匹配 | 名称、拼音（若实现）、目标路径模糊 |
| 默认动作 | 启动应用 |
| 次要动作 | 打开文件位置、以管理员运行（若可行）、固定到收藏 |
| 刷新 | 启动后后台枚举；设置中「重建应用索引」 |

---

### 4.4 历史与收藏

| 类型 | 行为 |
|------|------|
| 历史 | 每次成功执行记一条；空窗时靠前；可设条数上限 |
| 收藏 | 用户钉住的项，空窗与搜索均可加权置顶 |
| 清除 | 设置中清除历史；单项可「从历史移除」 |
| 隐私 | 不上传；本地存储；卸载可选手动清数据 |

---

### 4.5 文件搜索（P1 简化 / P2 完整）

| 阶段 | 能力 |
|------|------|
| 简化 | 仅用户配置的若干目录；按文件名 |
| 完整 | 多目录、后缀过滤、FTS、打开/打开目录/复制路径 |

**默认关闭全盘扫描**，避免影响系统性能；引导用户添加文档/项目目录。

---

### 4.6 内置小工具（P1，可不走插件）

以「输入即用」为主，例如：

| 工具 | 触发示例 | 动作 |
|------|----------|------|
| 计算器 | `1+2*3` | 显示结果；Enter 复制 |
| 编码转换 | 选中或输入后命令 | Base64 / URL 等（可后置） |
| 颜色 | `#FFAA00` | 预览；复制格式 |
| 系统关机类 | `锁屏` `注销` | 确认后执行（高危需确认） |

原则：**真正高频的进内置**；长尾进插件。

---

### 4.7 网页快搜 / 前缀命令（P1）

| 示例前缀 | 行为 |
|----------|------|
| `g keyword` | 浏览器打开 Google 搜索（可配引擎） |
| `bd keyword` | 百度等 |
| 自定义 | 设置里配置 `前缀 → URL 模板` |

也可由插件提供同等能力；内置只做最小集合。

### 4.8 插件功能（用户视角）

#### 发现与安装（P1 本地 / P3 市场）

| 能力 | 说明 |
|------|------|
| 本地安装 | 选择文件夹或 `.lap`（自定义包格式，名称可再定）安装 |
| 开发加载 | 指定开发目录，热重载清单（开发者模式） |
| 启用/禁用 | 列表开关，即时生效 |
| 卸载 | 删注册与可选数据 |
| 市场 | 后期：浏览、搜索、一键安装、更新 |

#### 使用方式

1. **前缀模式**（主推荐）：输入 `echo hello` 只走该插件  
2. **关键字模式**：插件注册关键字，全局结果中出现  
3. **全局贡献**（默认关）：无前缀也参与融合，需用户/权限允许  

#### 结果与执行

- 插件返回列表项：标题、副标题、图标、动作  
- 执行后：关闭面板 / 保持 / 复制文本 / 打开 URL / 报错提示  
- 插件需要独立 UI（截图选区等）时允许自建顶层窗，主搜索窗可先隐藏  

#### 权限（用户可见）

安装或首次用到时说明，可在设置中随时收回：

| 权限 | 用户文案示例 |
|------|----------------|
| 剪贴板 | 读取/写入剪贴板 |
| 文件读/写 | 访问指定文件 |
| 网络 | 访问网络 |
| 运行命令 | 运行本机程序 |
| 截图 | 屏幕截图 |
| 通知 | 发送系统通知 |

## 5. 用户场景（User Stories）

### 场景 A — 快速开应用

> 开发中要开终端：`Alt+Space` → `wt` → Enter，1 秒内完成。

### 场景 B — 重复操作

> 早上常开的三个工具出现在空窗历史，方向键两次 Enter。

### 场景 C — 插件命令

> 安装「JSON 格式化」插件，输入 `json ` 粘贴内容，Enter 复制美化结果。

### 场景 D — 改热键

> 与其它软件冲突：设置 → 热键 → 选 **Ctrl+Space** → 立即生效。

### 场景 E — 插件崩溃

> 某插件无响应：主程序仍可搜应用；设置里该插件标红，可禁用。

### 场景 F — 演示/游戏

> 托盘「暂停热键」，避免误触；结束后恢复。

| 状态 | 文案示例 |

## 10. 功能验收标准（产品向）

| 编号 | 标准 |
|------|------|
| F1 | 默认 Alt+Space 可唤起；设置可改为 Ctrl+Space 并生效 |
| F2 | 能搜索并启动开始菜单中的常见应用 |
| F3 | 空输入展示历史；执行后历史更新 |
| F4 | Esc / 失焦策略符合设置 |
| F5 | 本地插件可安装、出现前缀命令、可执行、可卸载 |
| F6 | 禁用或崩溃插件不影响应用搜索 |
| F7 | 托盘可退出与暂停热键 |
| F8 | 主界面在 100%/150% DPI 下可用、不裁切关键控件 |
