对插件目录的内容清单做 Ed25519 签名，产出与 spark-sign CLI 字节级一致的 signature.json。规范详见 插件开发/插件签名规范.md。
仅签官方仓库（工具已硬编码，不签其他仓库）。路径指到包含 plugin.json 的那一层。签的是该目录下所有文件（signature.json 自身除外），路径以该目录为根的 POSIX 相对路径。签名对象 = 仓库内字节，请确保发布/安装的插件文件与所签仓库字节逐字节一致（勿在发布流程里做换行/编码转换，否则 host 重算哈希会判 Invalid）。Gitee 为 GitHub 官方仓库的镜像，两边字节应一致；任一平台签出的 signature.json 通用。
浏览器把所选目录所有文件读入内存计算哈希，纯离线计算，不上传任何文件。
