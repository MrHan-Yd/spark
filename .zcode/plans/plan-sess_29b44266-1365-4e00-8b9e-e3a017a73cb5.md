## 插件本地更新机制（按版本号决定覆盖行为）

### 需求（已与用户确认）
纯本地目录更新，无远程源。重复安装已装插件时按版本号比对：
- **新版 > 已装**：直接覆盖（静默更新）
- **同版**：直接覆盖（重装）
- **旧版 < 已装**：先弹窗提示用户，用户同意才覆盖

### 现状关键缺口
1. `version` 是不透明 `String`，无任何比较逻辑（全代码库无 semver 用法）
2. `install_from_dir`（`lib.rs:233`）在插件 id 已存在时**直接报错拒绝**，无覆盖路径
3. `PluginState` 只存 `enabled`+`granted`，卸载会清空——覆盖时需保留
4. native 插件进程可能在运行，Windows 下无法删除占用中的 .exe——覆盖前必须先关进程
5. IPC `PluginInstallParams` 只有 `path`，无 `force`；返回值只有裸 `{id}`，无法表达"需确认降级"
6. UI 安装失败只 `catch` 异常展示 `ex.Message`，无降级确认流程

### 改动清单

#### 1. 版本比较 — `crates/plugin-manager/src/manifest.rs`
新增 `pub fn cmp_version(a: &str, b: &str) -> std::cmp::Ordering`：
- 手写宽松解析（不引 semver crate）：去前导非数字（处理 `v0.1.0`）→ 按 `.` 分段取前 3 段 `u32`（缺失补 0，解析失败补 0）→ 元组比较
- 双方都解析失败时回退字符串比较
- 与 host 自更新 C# 端 `ParseVersion` 行为一致
- 配 4 个单元测试（升/平/降/带 v 前缀/非数字回退）

#### 2. 安装/覆盖核心 — `crates/plugin-manager/src/lib.rs`
新增类型：
```rust
#[derive(Debug, Clone, Copy, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum InstallAction { Installed, Updated, ConfirmDowngrade }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PluginInstallOutcome {
    pub id: String,
    pub action: InstallAction,
    pub version: String,                  // 新装版本
    pub previous_version: Option<String>, // 旧版本（全新装为 None）
}
```
重写 `install_from_dir(&mut self, src: &Path, force: bool) -> Result<PluginInstallOutcome, PluginError>`：
- 加载+校验源 manifest，取 `id`+`new_version`
- `dest = plugins_dir/id`
- **dest 不存在**：走原安装路径 → `action=Installed`
- **dest 存在**：加载旧 manifest 取 `old_version`，用 `cmp_version` 比对
  - `!force && new < old` → 返回 `ConfirmDowngrade`（**不写盘**，纯探查，让 UI 弹窗）
  - 否则（force=true 或 new>=old）→ 覆盖：
    1. `self.native.shutdown_plugin(&id)`（关 native 进程，见第 3 点）
    2. `fs::remove_dir_all(&dest)` 删旧目录
    3. `copy_dir_recursive(src, dest)` 拷新
    4. 从 dest 重载 manifest
    5. `retain` 移除旧内存条目（仅 Standard）
    6. 读现有 `enabled_of`+`granted_of`（**不清空 state**），granted 裁剪为与新 manifest 声明权限的交集
    7. push 新 `LoadedPlugin`
    8. `action=Updated`
- `warn_keyword_conflicts()` + 返回 outcome

#### 3. Native 进程按 id 关停 — `crates/plugin-manager/src/native.rs`
`NativeRuntime` 新增：
```rust
pub fn shutdown_plugin(&mut self, id: &str) {
    if let Some(mut proc) = self.procs.remove(id) { proc.shutdown(); }
}
```
（`procs: HashMap<String, NativeProcess>` 已按 id 索引，`shutdown_all` 已有同款逻辑可参考）

#### 4. IPC 协议 — `crates/ipc/src/protocol.rs`
`PluginInstallParams` 加字段：
```rust
#[serde(default)]
pub force: bool,
```
返回值由 host 直接序列化 `PluginInstallOutcome`，protocol.rs 不需重复定义结果结构（ipc_server 用 `serde_json::to_value`）。

#### 5. Host 接线 — `crates/host/src/app.rs` + `ipc_server.rs`
- `app.rs` `plugin_install`：签名改 `(&mut self, path: &str, force: bool) -> Result<PluginInstallOutcome>`，透传 `force`
- `ipc_server.rs` `PluginInstall` 分支（415 行）：解析 `params.force`，调 `g.plugin_install(&params.path, params.force)?`，用 `serde_json::to_value(outcome)` 回填 result

#### 6. C# UI — `HostIpcClient.cs` + `MainWindow.xaml.cs` + 新 DTO
- `Models/PluginInstallOutcomeDto.cs`（新）：`{ Id, Action, Version, PreviousVersion }`
- `HostIpcClient.cs` `PluginInstallAsync(string path, bool force=false)`：参数加 `force`，返回类型从 `Task<string>` 改为 `Task<PluginInstallOutcomeDto>`（解析 result 对象而非取 `id` 字段）
- `MainWindow.xaml.cs` `OnInstallPlugin`（3220 行）重写流程：
  1. 选目录 → `PluginInstallAsync(dir)`（force=false）
  2. `outcome.Action`：
     - `"installed"` → 状态"已安装：{name}"
     - `"updated"` → `PluginWindowHost.CloseIfOpen(outcome.Id)` → 状态"已更新到 v{version}"
     - `"confirm_downgrade"` → `ContentDialog`「检测到旧版本（已装 {previous}，将安装 {version}），是否继续覆盖？」
       - 用户确认 → `PluginWindowHost.CloseIfOpen(outcome.Id)` → `PluginInstallAsync(dir, force:true)` → 状态"已降级安装到 v{version}"
       - 取消 → 状态"已取消"
  3. 末尾 `LoadPluginsAsync()` 刷新列表
- 复用现有 `ConfirmDestructiveAsync`（4275 行）模式做降级确认弹窗
