## 背景（已定位根因）

**问题 1：首次启动应用少，唤醒后才完整**
- `ui/Spark.UI/MainWindow.xaml.cs:159-173` Loaded 时若 host 未就绪，`QueryAsync` 返回 DemoData（仅 5 条）；`MaintainHostConnectionAsync`（369-381 行）每 2s 重连但**连接成功后从不刷新结果**，直到热键唤醒（`ShowLauncher` → `RefreshResultsAsync("")`）才有完整列表。

**问题 2：搜索结果全是快捷方式**
- `crates/index/src/apps.rs:41-120`：每个 `.lnk` 直接作为独立 Candidate，**不解析目标**（title=lnk 文件名、target/icon=lnk 路径），无合并、无过滤 → "Google Chrome" / "Chrome 无痕模式" / "卸载 Google Chrome" 各成一条，图标还带快捷方式小箭头。

## 修复 1（UI 侧）：连接成功即自动刷新

`ui/Spark.UI/MainWindow.xaml.cs` `MaintainHostConnectionAsync`：
- 记录上一轮 `_host.IsConnected` 状态；检测到「断开 → 连接成功」跃迁时，用 `DispatcherQueue.TryEnqueue` 补一次 `RefreshResultsAsync(QueryBox.Text)`（首启时空查询 → 拉完整列表，替换 DemoData）。

## 修复 2（Rust 索引层，热路径进 crates/）

### 2a. `crates/index/Cargo.toml` 加 windows 依赖
```toml
windows = { version = "0.61", features = ["Win32_Foundation", "Win32_UI_Shell", "Win32_System_Com"] }
```
（与 host 同版本；IShellLinkW/CLSID_ShellLink 在 Win32_UI_Shell，IPersistFile/CoCreateInstance/CoInitializeEx 在 Win32_System_Com，实现时验证 feature 归属）

### 2b. 新建 `crates/index/src/lnk.rs`
`resolve_lnk(path) -> Option<LnkInfo>`：
- `CoInitializeEx` → `CoCreateInstance(CLSID_ShellLink, IShellLinkW)` → `QueryInterface::<IPersistFile>` → `Load(path, STGM_READ)`
- `GetPath`（真实目标）、`GetArguments`（参数）、`GetIconLocation`（自定义图标）
- 任何一步失败返回 `None`（调用方兜底）

### 2c. 重写 `crates/index/src/apps.rs` 收集/合并
- 收集时对 `.lnk` 解析；解析成功且目标存在：
  - **垃圾过滤**（现有 uninstall/卸载/unins/readme/help 规则 + 目标 exe 名含 unins 等）
  - 目标 exe 归一化：去引号 + `canonicalize`（比较时 lowercase）
- **按 exe 分组合并**：
  - 主条目：组内选最优 lnk（优先无参数 → 参数短 → 标题短）；`id = app:{hash(canonical_exe)}`（稳定，lnk 删除不影响历史）；`target = exe`；`icon = lnk 指定图标或 exe`（→ UI 提取真实图标，无快捷方式小箭头）；score 取组内最大 + mtime boost
  - 附属 lnk（带参数等）：**不进独立候选**，转为主条目 `actions`：`Action { id: hash(lnk路径), title: lnk 文件名, is_default: false, target: lnk 路径 }`
- 解析失败的 `.lnk`、`.exe`、`.url`：保持现状独立收录（兜底不丢应用）
- 合并/过滤逻辑抽成纯函数，便于单测

### 2d. 动作级 target 支持
- `crates/core/src/candidate.rs`：`Action` 加 `#[serde(default, skip_serializing_if = "Option::is_none")] target: Option<String>`
- `crates/host/src/app.rs` `invoke`：按 `action_id` 找到 action，`action.target.or(item.target)` 作为实际启动目标（open/runas/reveal 逻辑不变）

## 修复 2（UI 层呈现）

- `ui/Spark.UI/Models/CandidateDto.cs`：加 `ActionDto` + `Actions` 列表（JSON 映射对齐 serde snake_case）
- `ui/Spark.UI/MainWindow.xaml.cs` `BuildItemMenu`：加「打开方式」`MenuFlyoutSubItem`，列出非默认附属动作（id 非 open/runas/reveal），点击 → `InvokeAsync(item.Id, action.Id, text)`
